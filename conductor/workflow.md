# Workflow

## Development Process
1. **Research & Planning:** Define requirements and update product/tech-stack docs.
2. **Track Creation:** Create a new track for significant features or fixes.
3. **Implementation:** Surgical changes with validation.
4. **Testing:** Automated tests for all changes.
5. **Review:** Ensure consistency with project standards.

## Commit Guidelines
- Use clear, concise commit messages.
- Focus on "why" rather than just "what".
