# Tech Stack

## Backend
- **Framework:** Spring Boot 3
- **Language:** Java
- **Database:** MySQL
- **Build Tool:** Maven

## Frontend
- **Framework:** React
- **Build Tool:** Vite
- **Language:** TypeScript
- **UI Library:** Material UI (MUI)
- **Web Server:** Nginx (for production/docker)

## Infrastructure
- **Containerization:** Docker, Docker Compose
